# Restaurant Ordering Website

A responsive frontend restaurant ordering website built with React and Tailwind CSS.

## Features

- 🍔 Interactive food menu
- 🔍 Search menu items
- 🏷️ Filter menu by category
- 🛒 Add and remove items from cart
- ➕ Update item quantities
- 🌙 Dark mode
- 📱 Responsive design
- ⚡ Interactive user interface

## Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- HTML
- CSS

## Project Overview

This project is a frontend restaurant ordering interface where users can browse food items, search and filter the menu, add items to their cart, change quantities, and switch between light and dark modes.
